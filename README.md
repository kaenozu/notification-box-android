# 通知箱

Android 向けの通知整理 MVP です。

## 含まれるもの

- OSから取得する実際の通知権限状態
- 通知の自動分類ロジック
- 観察モードでの通知履歴確認
- 通知ごとの手動分類補正
- アプリ別の即時 / あとで確認 / 低優先ルール
- 手動指定 > アプリ別ルール > 自動分類の優先順位
- 端末内だけで集計する分類・補正統計
- 個別ピン留め、個別削除、確認付き全消去
- `NotificationListenerService` からの通知履歴同期
- Roomによる端末内の通知履歴・ルール保存
- 通知の再投稿・削除・リスナー再接続時の状態同期

## データ保持とプライバシー

- 通知タイトルと本文は外部APIへ送信せず、端末内だけで処理します
- 分類統計には通知タイトルと本文を保存しません
- 非アクティブかつピン留めされていない履歴は7日後に自動削除します
- 履歴は原則500件を上限とし、ピン留め通知は自動削除から保護します
- 通知履歴を全消去しても、ユーザーが設定したアプリ別ルールは残ります
- アプリのAndroidバックアップは無効です
- 通知タイトルや本文をアプリログへ出力しません

## 現在の範囲

- 初期は観察モードを起点にします
- 外部APIやクラウド同期は入れていません
- 現時点ではOS通知の取消・スヌーズ・ダイジェスト配信は実装していません
- 「整理」モードの実際の通知制御は、明示的なユーザールールと安全除外条件を整えた後に接続します
