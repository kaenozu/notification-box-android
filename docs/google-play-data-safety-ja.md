# Google Play Data safety 入力案

対象: 通知箱 v0.1.0

この文書はPlay Console入力時の作業票です。最終提出時には、実際にアップロードするAABの依存関係、権限、通信、およびGoogle Playの最新の質問文を再確認してください。

## 推奨回答

### データの収集または共有

- アプリが必須のユーザーデータタイプを収集または共有するか: **いいえ**

根拠:

- 通知内容と分類情報は端末内だけで処理・保存する。
- アプリに`INTERNET`権限がない。
- 外部API、広告、解析、クラッシュ収集、クラウド同期SDKがない。
- 他アプリや第三者へデータを転送する機能がない。

Google PlayのData safety定義では、端末外へ送信されないオンデバイスのアクセス・処理は「収集」の申告対象外とされている。ただし、通知内容へのアクセス自体はプライバシーポリシーとアプリ内の明示説明へ記載する。

### データ共有

- 第三者との共有: **なし**
- 広告目的の共有: **なし**
- 販売: **なし**

### セキュリティ慣行

- 転送中の暗号化: **該当する転送なし**
- データ削除方法: **アプリ内から履歴・統計・ルールを削除可能**
- アカウント作成: **なし**
- アカウント削除URL: **対象外**
- 独立したセキュリティレビュー: **未実施のため申告しない**
- Familiesポリシー: **子どもを主対象としない**

## Play Console入力前の必須再確認

- [ ] Release AABのManifestに`INTERNET`権限がない。
- [ ] Release AABに広告、解析、クラッシュ収集、リモート設定SDKがない。
- [ ] Release AABが通知内容を端末外へ送信しない。
- [ ] Release AABが通知内容を別アプリへ共有しない。
- [ ] ストア上の開発者名とプライバシーポリシーの開発者表記が一致する。
- [ ] プライバシーポリシーURLがHTTPS、一般公開、非PDF、地域制限なしである。
- [ ] アプリ内の初回説明が通知アクセス設定を開く直前に表示される。
- [ ] ユーザーの肯定的操作なしに通知アクセス設定を開かない。
- [ ] 「データを収集しない」というData safety表示と、端末内アクセスを説明するプライバシーポリシーが矛盾していない。

## 変更時に回答を見直す機能

次を追加した場合は、Data safetyを必ず再評価する。

- クラッシュ収集
- アクセス解析
- 広告
- クラウド同期
- バックアップ
- 外部AI分類
- サポートへのログ送信
- 通知内容の共有またはエクスポート
- アカウント機能
- Push通知またはリモート設定

- Google Play Console Help: User Data policy
