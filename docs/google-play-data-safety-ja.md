# Google Play Data safety 入力案

対象: 通知箱 v0.1.0以降の決済インボックス統合版

この文書はPlay Console入力時の作業票です。最終提出時には、実際にアップロードするAABの依存関係、権限、通信、およびGoogle Playの最新の質問文を再確認してください。

## 推奨回答

### データの収集または共有

- アプリが必須のユーザーデータタイプを収集または共有するか: **いいえ（公開対象AABが現在の完全端末内設計を維持する場合）**

根拠:

- 通知内容、分類情報、通知から抽出した金額・店舗・取引種別は端末内だけで処理・保存する。
- アプリに`INTERNET`権限がない。
- 外部API、広告、解析、クラッシュ収集、クラウド同期SDKがない。
- 他アプリや第三者へデータを転送する機能がない。

Google PlayのData safety定義では、端末外へ送信されないオンデバイスのアクセス・処理は「収集」の申告対象外とされる扱いがある。ただし、決済通知には財務情報に相当する内容が含まれ得るため、最終提出時はPlay Consoleの最新の質問文と公開対象AABを基準に再確認する。通知内容および決済の派生情報への端末内アクセスは、プライバシーポリシーとアプリ内説明へ明記する。

### データ共有

- 第三者との共有: **なし**
- 広告目的の共有: **なし**
- 販売: **なし**

### セキュリティ慣行

- 転送中の暗号化: **該当する転送なし**
- データ削除方法: **アプリ内から通知履歴、決済履歴、統計およびルールを削除可能**
- アカウント作成: **なし**
- アカウント削除URL: **対象外**
- 独立したセキュリティレビュー: **未実施のため申告しない**
- Familiesポリシー: **子どもを主対象としない**

## Play Console入力前の必須再確認

- [ ] Release AABのManifestに`INTERNET`権限がない。
- [ ] Release AABに広告、解析、クラッシュ収集、リモート設定SDKがない。
- [ ] Release AABが通知内容や決済の派生情報を端末外へ送信しない。
- [ ] Release AABが通知内容や決済の派生情報を別アプリへ共有しない。
- [ ] 決済イベント用テーブルに通知タイトル・本文を複製していない。
- [ ] 決済解析・保存の診断状態に通知内容、金額、店舗名、通知識別子を保存していない。
- [ ] 決済履歴の一括削除が公開対象AABで動作する。
- [ ] ストア上の開発者名とプライバシーポリシーの開発者表記が一致する。
- [ ] プライバシーポリシーURLがHTTPS、一般公開、非PDF、地域制限なしである。
- [ ] アプリ内の初回説明が通知アクセス設定を開く直前に表示される。
- [ ] ユーザーの肯定的操作なしに通知アクセス設定を開かない。
- [ ] 「データを収集しない」というData safety表示と、端末内で通知・決済情報へアクセスする説明が矛盾していない。
- [ ] Play Consoleの最新定義で、完全端末内の財務情報処理が申告対象外であることを再確認した。

## 変更時に回答を見直す機能

次を追加した場合は、Data safetyを必ず再評価する。

- クラッシュ収集
- アクセス解析
- 広告
- クラウド同期
- バックアップ
- 外部AI分類
- サポートへのログ送信
- 通知内容または決済情報の共有・エクスポート
- CSV出力
- アカウント機能
- Push通知またはリモート設定
- 複数端末同期
- 家族共有
