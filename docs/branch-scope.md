# Branch scope

The `agent/phase1-hardening-complete` branch contains application, tests, documentation, and CI changes required to consolidate the Phase 1 dry-run stack and address the full-source review findings.

The payment-inbox integration branch additionally includes the Room 3-to-4 migration, PayPay-only local parsing, derived payment-event storage, payment UI, regression tests, and privacy/data-safety documentation.

It intentionally excludes tag, release, distribution, production OS notification operations, cloud sync, external payment APIs, CSV export, and monetization.
